# Robot-Dog-Servo-Mounting-Bracket
 

## Part name
Robot Dog Servo Mounting Bracket

## Task scope
This submission is for **Task 1 only**. It presents a selected mechanical shape, its estimated dimensions, and a complete 3D model exported in STL format. The design is a functional L-shaped mounting bracket suitable for fixing a servo motor or a small robotic mechanism.

## Design dimensions

| Feature | Dimension |
|---|---:|
| Overall width | 60 mm |
| Overall depth | 40 mm |
| Overall height | 35 mm |
| Material thickness | 4 mm |
| Base mounting holes | 4 × Ø4.5 mm clearance holes |
| Servo mounting holes | 6 × Ø3.4 mm clearance holes |
| Cable opening | 12 × 6 mm |
| Side reinforcement | 2 triangular gussets |

## Design description
The part consists of a horizontal base plate and a vertical mounting plate joined at 90 degrees. The base contains four M4 clearance holes for attaching the bracket to a robot frame. The vertical plate contains two rows of three M3 clearance holes, allowing a servo or another small actuator to be mounted at different positions. A central cable opening is included, and two side gussets increase rigidity.
